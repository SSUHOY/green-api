# MAX / Telegram Chat на React + Green-API

Веб-интерфейс чата с поддержкой отправки и получения текстовых сообщений через GREEN-API.  
Разработан в рамках тестового задания на позицию Frontend Developer (React).

![Chat Screenshot](./screenshots/chat-demo.png) <!-- добавите позже -->

## 🚀 Возможности

- ✅ Отправка текстовых сообщений
- ✅ Получение входящих сообщений в реальном времени (Long Polling)
- ✅ Оптимистичный UI (мгновенное отображение отправленных сообщений)
- ✅ Поддержка Telegram, WhatsApp и MAX
- ✅ Автоматическая очистка очереди уведомлений
- ✅ Обработка ошибок сети и таймаутов
- ✅ Адаптивный интерфейс в стиле web.max.ru

## 🛠️ Стек технологий

- **React 18** + **TypeScript**
- **Redux Toolkit** — управление состоянием
- **Vite** — сборка и dev-сервер
- **CSS Modules / SCSS** — стилизация
- **Green-API** — интеграция с мессенджерами
